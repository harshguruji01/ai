Frequently Asked Questions

How do GuruAI usage allowances work? ▼

Registered members receive 20 requests per 24-hour rolling window and 5 high-definition image creations, while guests receive 8 requests per 24-hour window (image generation is exclusive to registered members). Every 24 hours, all limits automatically refresh.

How do I generate hyper-realistic images? ▼

In the GuruAI chat composer, toggle the Image Studio icon (or type prompts starting with "Generate image:"). Logged-in members receive 5 high-resolution Stable Diffusion XL image generations every 24 hours.

Is my chat history and personal data private? ▼

Yes. All user chat history and images are secured using PostgreSQL Row Level Security (RLS). Only your authenticated session can access, view, or delete your resources.

What model powers GuruAI? ▼

GuruAI uses Guru-Flash 1.1, optimized for extreme speed, high context windows, complex reasoning, code generation, and multi-lingual Indian dialects (English, Hindi, Hinglish).
